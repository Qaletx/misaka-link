# qaletx link

面向客户的简洁桌面代理客户端：账号密码登录、选择线路、一键连接。支持三种账号角色、多私有线路分配、个人线路云同步和逐条真实延迟测试。当前版本 0.5.2。

## 宝塔部署

只上传 `server.js` 和 `.env`，**无需 package.json、node_modules 或 npm install**。服务端仅使用 Node.js 内置模块。

1. 复制 `.env.example` 为 `.env`，填写至少 32 字符的随机密钥和两个初始密码。
2. 宝塔 PM2 添加项目，启动文件选择 `server.js`，选择受维护的 Node.js LTS 版本，单实例 fork 模式，关闭 watch。
3. 访问 `/api/health`，返回 `ok: true` 即已启动。
4. 升级时先停止 PM2，备份整个 `data/` 和 `.env`，覆盖 `server.js` 并重启。首次升级前在 `.env` 添加 `MISAKA_PRIVATE_NODE_URI` 可迁移原默认私有线路；不要覆盖旧账号数据。

完整面板字段、权限、HTTPS 反向代理与升级说明见 [宝塔部署说明](server/BAOTA-DEPLOY.md)。Node.js 18+ 可运行。首次启动自动创建 `data/state.json`，旧版 `users.json` 会自动迁移并保留原文件。会话存在内存，重启后需要重新登录。**先升级服务端，再使用 0.5 客户端。**

0.5.1 修复连接时等待过久及托盘退出反馈：连接前先检查 10808 端口，连接中可取消并立即中止网络探测；退出时会取消等待、恢复代理，并在托盘显示退出进度。服务端 API 与 0.5.0 相同。

0.5.2 修复后台程序连接临时端口时切换线路、取消和托盘退出可能一直等待的问题；线路列表改为先选择再确认，已连接时确认会自动切换并重连。默认端口仍为 10808，可在“偏好设置”中改为其他本地端口，断开连接后生效并保存在本机。服务端无需升级。

## 桌面功能

- 登录页仅展示账号和密码，服务器地址通过构建变量 `VITE_API_URL` 固定。
- 1020 × 700 默认窗口，自定义图标、系统托盘；关闭窗口收起到托盘，托盘退出或退出登录会断开。
- sing-box 配置先校验，再经节点完成实际请求，成功后才开启系统代理。
- 恢复连接前的系统代理、PAC 与绕过设置；若其他软件更改代理则保留其更改。
- 核心异常退出时清理代理，主进程异常退出由独立守护进程尝试恢复；恢复失败保留记录供下次启动处理。
- 真实会话上传、下载、连接时长，脱敏诊断日志；连接过程取消与连续切换串行处理。
- 全局代理 / 绕过局域网（私有 IP）。系统代理覆盖遵循系统代理设置的应用，不等于全设备 TUN；没有“中国大陆分流”的虚假开关。
- 本地 HTTP/SOCKS 混合代理端口默认 `10808`，可在“偏好设置”中手动修改；被其他软件占用时提示换端口或退出对应代理程序，不抢占端口。
- 每条线路可单独测试连通性与实际请求延迟（ms）；独立启动核心，不改变系统代理或当前连接。
- root 在“我的线路”创建多条私有线路、将个人线路转为私有、逐条分配用户；也可从用户管理关闭某人的全部私有线路权限。私有分享链接不传给页面，不提供复制/导出。
- 管理员、普通用户、共用用户三种角色；root 是受保护的最高管理员。共用账号不能自行改密，管理员可重置；普通管理员只能管理普通/共用账号。
- 管理员及普通用户手动导入的线路保存到账号数据库，换电脑登录即可同步。共用账号导入的线路仅留本机；旧版全局本机线路需要本人确认后迁移。
- 每条线路支持命名和备注；私有线路普通用户的备注只对本人可见。云端个人线路编辑检测冲突，避免另一台电脑的修改被静默覆盖。
- 连接和测速前由主进程重新获取授权；连接中每 15 秒检查，撤权、删除、配置改变会断开，连续两次服务器访问失败也会断开。

## 支持的链接

Hysteria2、TUIC、Trojan、VLESS（含 Reality）、VMess、Shadowsocks（SIP002、旧格式与 2022）、SOCKS5、HTTP/HTTPS；相应协议支持 WS、gRPC、HTTP、HTTPUpgrade 等已实现传输。

未知参数和不支持的组合会说明原因并拒绝导入。SS 插件、XHTTP、mKCP、gRPC multi、Hysteria2 `pinSHA256` 等不在当前实现范围。不能承诺任意 Clash/V2Ray 配置均兼容。

## 构建

桌面开发使用 Node.js 22.12+，`npm ci` 安装锁定依赖。服务端部署无需安装这些依赖。

```sh
npm test
npm run build
node tests/electron-smoke.cjs
npm run dist:win
```

将原版 sing-box 1.14.3 核心放在 `core/`：Windows 使用 `sing-box.exe`（上游 legacy-windows-7 amd64 构建）；macOS 使用 `sing-box-amd64`（legacy-macos-10.13）与 `sing-box-arm64`。Windows 安装版与便携版分别输出 `setup` 和 `portable` 文件名。

私有线路配置保存在账号服务端。客户端构建不再需要节点 Secret，安装包明确排除旧版 `electron/private-node.cjs`。`MISAKA_PRIVATE_NODE_URI` 只用于服务端首次创建或迁移数据库；后续在客户端以 root 管理线路。

macOS 工作流 [build-macos.yml](.github/workflows/build-macos.yml) 使用 GitHub macOS runner，客户端源码更新时自动运行，也可手动运行 Actions。可用仓库变量 `MISAKA_API_URL` 指定 API 地址，在 Artifacts 下载 universal DMG。没有 Apple 开发者签名和公证时，macOS 会进行安全拦截，需要用户手动允许；客户分发前建议配置签名。

## 实际边界

代理凭据最终需要在客户电脑执行，隐藏复制入口不能阻止逆向提取。真正限制外部使用需要 Hysteria2 服务端按用户认证、发放可撤销凭据并执行额度。当前账号服务管理客户端登录和配置发放，不负责代理服务器流量计费或撤销已获得的节点密码；旧版客户端也不会执行新版授权开关。

默认 API 配置沿用现有部署地址；对外使用请通过宝塔配置 HTTPS，并以 `VITE_API_URL` 重建客户端。当前 Windows x64 构建基于 Electron 22，以兼顾旧系统；没有 Win7 或 macOS 实机验证结果时，不应宣称所有系统已验收。Electron 22 已属旧运行时，旧系统兼容和运行时安全更新存在取舍。

第三方核心版本、源代码和许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
